# Data sources — Trend Duel

Generated by `tools/build_elements.py` from the `mendeleev` Python package, version 1.3.0. The game uses these numbers for ORDERING; a student's textbook may print slightly different values from a different compilation.

## Stats

### `radius_pm` — Atomic radius (pm)
- mendeleev field: Element.covalent_radius_cordero (pm)
- dataset: Covalent radii, Cordero et al.
- citation: B. Cordero, V. Gómez, A. E. Platero-Prats, M. Revés, J. Echeverría, E. Cremades, F. Barragán, S. Alvarez, "Covalent radii revisited", Dalton Trans. 2008, 2832-2838. doi:10.1039/b801115j
- note: Rounded to the nearest picometre. mendeleev averages carbon's three valence values, and the low- and high-spin values for Mn, Fe and Co. Null for all six noble gases by Trend Duel's rule (kickoff §2), even though the dataset lists values.

### `ie1_kjmol` — Ionization energy (kJ/mol)
- mendeleev field: Element.ionenergies[1] (eV), converted x 96.485 to kJ/mol
- dataset: First ionization energy, NIST Atomic Spectra Database
- citation: A. Kramida, Yu. Ralchenko, J. Reader and NIST ASD Team, NIST Atomic Spectra Database (ver. 5.11), physics.nist.gov/asd — as cited by the mendeleev docs.
- note: Rounded to one decimal after conversion.

### `en_pauling` — Electronegativity
- mendeleev field: Element.en_pauling
- dataset: Pauling electronegativity, CRC Handbook
- citation: W. M. Haynes (ed.), CRC Handbook of Chemistry and Physics, 95th ed., CRC Press, 2014 — as cited by the mendeleev docs.
- note: Null wherever the dataset is blank (He, Ne, Ar, Kr, Rn). Xe carries a value in this dataset and keeps it.

### `mass` — Atomic mass (u)
- mendeleev field: Element.atomic_weight (Da)
- dataset: Standard atomic weights, IUPAC-CIAAW
- citation: J. Meija et al., "Atomic weights of the elements 2013 (IUPAC Technical Report)", Pure Appl. Chem. 88(3), 265-291, 2016, doi:10.1515/pac-2015-0305; and IUPAC-CIAAW, Standard atomic weights, ciaaw.org/atomic-weights.htm — as cited by the mendeleev docs. Conventional values for interval elements; mass number of the longest-lived isotope for radioactive elements (Po, At, Rn).
- note: Stored to three decimals; displayed to two.

### `valence_e` — Valence electrons
- mendeleev field: derived: main-group column (IUPAC group 1-2 -> 1-2, 13-18 -> 3-8)
- dataset: Definition, not measurement
- citation: Kickoff §2: valence electrons equal the column index and have no exceptions. Helium is column 8 with 2 electrons total; the card follows the column rule the kickoff locked.
- note: He's valence_e is 8 by the column rule, which is the kickoff's explicit decision (invariant 4: valence_e == column for every card). Null for the ten d-block cards, which have no column (Phase 3 §2).

### `ea_kjmol` — Electron affinity (kJ/mol)
- mendeleev field: Element.electron_affinity (eV), converted x 96.485 to kJ/mol
- dataset: Electron affinity, CRC Handbook
- citation: W. M. Haynes (ed.), CRC Handbook of Chemistry and Physics, 95th ed., CRC Press, 2014 — as cited by the mendeleev docs.
- note: Positive = energy released when the atom gains an electron. Rounded to one decimal after conversion. Null for two reasons, listed under 'Electron affinity: the undefined cells' below: the dataset has no value (Ne, Mg, Kr, Rn, Mn, Zn), or its value is negative. The mendeleev docs say the negative values (He, Be, N, Ar, Xe) come from T. Andersen, Physics Reports 394 (2004) 157-313, and are specified for metastable ions; the game does not compare a metastable-ion energy with ground-state ones.

### `ionic_radius_pm` — Ionic radius (pm)
- mendeleev field: Element.ionic_radii -> IonicRadius.ionic_radius (pm), one row per card chosen by ION_TABLE: (charge, coordination VI, spin)
- dataset: Effective ionic radii, Shannon
- citation: R. D. Shannon, Acta Cryst. A 32 (1976) 751-767 — as cited by the mendeleev docs.
- note: One ion per card, six-coordinate, high spin where Shannon lists both (the ion table below). Stored exactly as listed (Al3+ 53.5) and shown to the nearest pm; comparisons use the stored value, so rounding never makes a tie. Null where the element has no common simple ion with a CN 6 entry; each such cell's reason is in the ion table.

## Undefined cells

A null in `elements.json` is a claim that the value is not comparable, not a missing number. Each is listed here and the invariant test checks both directions.

- undefined `radius_pm`: He, Ne, Ar, Kr, Xe, Rn
- undefined `en_pauling`: He, Ne, Ar, Kr, Rn
- undefined `valence_e`: Sc, Ti, V, Cr, Mn, Fe, Co, Ni, Cu, Zn
- undefined `ea_kjmol`: He, Be, N, Ne, Mg, Ar, Kr, Xe, Rn, Mn, Zn
- undefined `ionic_radius_pm`: H, He, C, N, Ne, Si, P, Ar, As, Kr, Xe, Po, At, Rn
